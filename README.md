# Release apps

Downloadable Android builds of Zohaib Nawaz's apps. Each app has one release with a fixed tag, and its APK is replaced in place on every new version, so the download link never changes.

| App | Download | Release notes |
| --- | --- | --- |
| Zohaib Portfolio | [zohaib-portfolio.apk](https://github.com/zohaib-nawaz/release-apps/releases/download/zohaib-portfolio/zohaib-portfolio.apk) | [Release](https://github.com/zohaib-nawaz/release-apps/releases/tag/zohaib-portfolio) |

## Install on Android

1. Download the APK on your phone.
2. Open it. If Android asks, allow "Install unknown apps" for your browser or file manager.
3. Tap Install.

Updates install over the old version because every build is signed with the same key.
